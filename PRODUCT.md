# Product

## Register

product

## Users

Developers and AI-agent operators who keep a local markdown vault (notes, skill
playbooks, feedback lessons) and want a GitHub-style file tree plus agent
tooling (MCP) over it. They work at a desk, often in low ambient light, for
long sessions — reading, writing, and reviewing agent-proposed edits. Primary
task on screen: read or edit a note. Secondary: see what agents changed and
approve it.

## Product Purpose

A local-first markdown workspace (a "shared brain") that humans and agents both
read and write, with every agent change legible and human-approved. Success =
the UI disappears: a calm reading/writing surface, obvious review affordances,
nothing competing with the prose.

## Brand Personality

Calm, precise, editorial. A desk lamp at night — warm light on paper, ink-dark
surroundings. Quiet confidence: the champagne accent appears only when it means
something (the primary action, links, live state).

## Anti-references

- Generic dark dev-tool: flat black planes, neon accents, glow stacks.
- The 2026 "AI cream" light theme (warm beige wash).
- SaaS dashboard chrome: card grids, hero metrics, gradient text, eyebrow
  labels on every panel.
- Palette drift: any hue outside the ink-blue ramp, champagne accent, and the
  declared semantic set is a bug, not variety.

## Design Principles

1. Prose first — typography carries the product; chrome recedes.
2. One accent, spent deliberately — champagne marks primary actions, links, and
   live state only; everything else is ink and neutral.
3. Elevation by light, not lines — layers separate via surface lightness;
   borders stay whisper-quiet.
4. Every color comes from the token ramp — no ad-hoc hex values.
5. Motion is felt, not seen — fast exponential easings; never decorative.

## Accessibility & Inclusion

WCAG AA: body and placeholder text ≥ 4.5:1, large text ≥ 3:1, against their
actual background. Visible focus rings on every interactive element.
`prefers-reduced-motion` honored everywhere. Dark-first; the light theme is
held to the same contrast standard.
